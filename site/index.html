Bayesian hierarchical
measurement modeling

A framework for combining response models with latent measurement structures, while retaining uncertainty in individual parameters and population relationships.

Documentation is being prepared.
The main branch currently contains repository infrastructure. A stable package release and the published API reference are not yet available.

Current development snapshot

An experimental snapshot is available on work/current-0.0.47.9000. See its README for installation, supported features and limitations.

API documentation

After an approved package-source update reaches main, this site will automatically build a pkgdown reference from the package's Rd documentation. This initial page does not expose an API reference from the development branch.

Scope and limitations

The package is experimental and supports explicitly documented model and computation profiles. Formal Bayes factors and density MCSE are not implemented. Engineering checks do not establish the validity of a scientific analysis.
