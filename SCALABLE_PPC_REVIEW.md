# Allocation-aware PPC engineering evidence

The R-only source review covered higher explicit main-API budgets, checked
allocation admission, larger complete geometry/statistic domains, insufficient
budget and overflow refusals, streaming acquisition, controller behavior,
whole-call RNG restoration, and passive historical/current metadata validation.
Synthetic fixtures assess engineering behavior, not posterior origin or inference.

The separate `bmeas_m3cs_rng_v2` native boundary gate passed one compile and two
fixed-parameter draws at O=1 and O=1001. Scientific support/count checks, an
independent probability oracle, and source/resource/executable/version receipts
passed. A sampler-header expectation was corrected and the first output
revalidated without a new native invocation; no source contract was weakened.

See SCALABLE_PPC.md for current policy, qualification boundaries and native-gate
scope. Neither this source review nor the tiny native gate establishes full
package release qualification, large-study performance, posterior inference, or
portable/archive M3 execution support. Exact archive and installed-package checks
are recorded separately with the release artifacts.
